# ♻️ Gorm Retry

Gortry (gorm-retry) is a gorm plugin that aims to retry queries that failed due
to a connection failure.
This would allow a database to reboot without queries immediately failing.

## ⬇️ Installation

```bash
go get github.com/survivorbat/go-gortry
```

## 📋 Usage

```go
package main
```
